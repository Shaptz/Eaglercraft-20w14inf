this is a 1.16 (20w14inf) backport of the 2020 Minecraft joke update. 
it uses a already existing 1.8.8 base and everything from 20w14inf was ported and tweaked to get a near identical replica of the 20w14inf snapshot.
while its not exactly 1:1, it comes very close.

Known issues:

the credits lie - i didn't add any new Easter eggs, as i am planing it for a future release.
performance issues depending on hardware when loading a non-core dimension.
some 1.16 (20w13b) game parts may have been left out by accident (combat update, swimming, est)

If you see anything not in-game to the real snapshot or any bugs; make a issue and i will look into it when i have time.
